# Rakuten Holdings Viewer

This simple Node.js site displays your Rakuten Securities holdings using a placeholder API call.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set the environment variable `RAKUTEN_API_KEY` with your API token.
3. Start the server:
   ```bash
   npm start
   ```
4. Open `http://localhost:3000` in your browser and click **保有銘柄を取得**.

Edit `server.js` to update the Rakuten Securities API endpoint.
